# LUDO GHOST

*It's a similar game to Ludo but with my own version*

A Ludo game of 4 players taking Ghost as topic, made with Python and Pygame.
It was my first Python project and first time using Pygame.

## Launching the game

1. Install Python 3, then: `pip install pygame`
2. Run: `python menu1.py`

## How to play

* Click **JOUER** in the menu.
* Press **SPACE** to roll the die.
* Click on the piece you want to move.
* You need a 6 to get a piece out of its home base.
* Landing on an opponent's piece sends it back to its home base.

## Features

* 4 players (green, white, purple, blue)
* Menu, die, timer, piece capturing
